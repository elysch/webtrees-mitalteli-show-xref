Bundled fonts
=============

mitalteli-symbols.woff

A subset (only the arrow and symbol blocks) of GNU Unifont 15.1.01 (unifont.otf and
unifont_upper.otf), bundled so the link symbols also display on devices (for example
Android phones) whose system fonts do not have them.

inside the file is "Mitalteli Symbols"; the original font has no Reserved Font Name.

How to replace the font
-----------------------
If you prefer another font (for example Noto Sans Symbols 2, which looks smoother than
Unifont, a pixel font), create a .woff file with only the blocks you need and replace this
file keeping its name (or change SYMBOL_FONT_FACES in ShowXrefModule.php). The unicode-range
must not be wider than what the file contains. Keep the license of the new font in this folder.

  pyftsubset Font.ttf --unicodes="U+2190-21FF,U+25A0-25FF,U+2700-27BF,U+27F0-27FF,U+2900-297F,U+2B00-2BFF,U+1F800-1F8FF" \
      --flavor=woff --layout-features= --no-hinting --name-IDs=0,1,2,3,4,5,6,13,14 \
      --output-file=mitalteli-symbols.woff
